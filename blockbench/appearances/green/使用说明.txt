绿色硬壳武器箱 · 平放 / 无印花 · Minecraft Java 1.20.1 · 模型文件

主工程：csgo_green_case_animated.bbmodel
按用户确认的方向平放箱子，原参考图的大面板作为顶部箱盖，提手与两枚扣件在正前方（北，-Z）。
箱盖绕背面（+Z）铰链向后掀开 0°～90°，内部朝前侧玩家展示。
保留绿色薄型硬壳、切角边框、加强筋和前侧提手；全部图标、放射图案与文字印花均未加入。
主壳尺寸 16×10.5×3.5 模型单位，提手、铰链和扣件有少量外凸。所有显示比例均匀缩放。
贴图实际尺寸 128×128，15 色，连续的像素高光与阴影，没有随机噪点。
箱体下半部仍为平面封顶，用灰色回字纹表现内部深度；上盖为连续灰框和纯深灰中心。

开合结构
root → body；root → lid → lock。body 固定，lid 为上盖，lock 为两枚前扣并随盖子移动。
提手固定在 body。Animate 面板有 closed、open、opened、close 四个动作。
open / close 各 0.5 秒，20 Hz 关键帧；闭合为默认姿态。
主工程为 Generic Model，内嵌 128×128 贴图，无需插件即可编辑和预览动画。
主工程以方块中心为 X/Z 原点，转轴 [0,1.64,5.62]；Java 导出对应 [8,1.64,13.62]。
保存协议为 4.10，Blockbench 4.12 可读取，Blockbench 5 会自动迁移动画方向；不要只手工改 format_version。

文件
csgo_green_case.png：128×128 贴图。
java_models/：Java 1.20.1 开 / 闭静态 JSON、Java Block/Item 工程和 body / lid / lock 分体 JSON。
geckolib/：供 Java 模组 GeckoLib 4 使用的 Geo 1.12.0 骨骼模型、1.8.0 动画 JSON 和贴图。
assets/csgobox/：上述模型资产按模组资源路径整理好的副本，普通物品入口默认关闭。
model_manifest.json：朝向、骨骼、转轴和动画名称；texture_layout.json：图集位置与配色。
本包仅包含模型、贴图、动画、预览和说明，没有新增模组代码或容器逻辑；当前为单箱模型。

预览与检查
preview_states.png：平放关闭 / 向后打开状态。
preview_closed.png、preview_half_open.png、preview_open.png、preview_front_open.png、preview_back.png：实际模型与 PNG 渲染。
validation.json：坐标、UV、分组、贴图与 0°～90° 每个整数角度的开合穿插检查，正常铰链接合除外。
codec_validation.json：与 Blockbench 官方 4.12 几何导出逻辑的比对、关键帧方向与新版迁移检查。
已检查文件与资产引用，未在 Minecraft 客户端实测。
