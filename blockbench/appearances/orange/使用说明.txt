橙色武器箱（无印花） · Minecraft 像素风格 · Java 1.20.1 · 模型文件

主工程：csgo_orange_case_animated.bbmodel
这是可直接在 Blockbench 编辑、预览动画的 Generic Model 工程，无需插件。
以用户提供的橙色硬壳武器箱为造型参考：橙色箱体、三枚前扣、嵌入式提手、侧边挂锁。
箱体采用阶梯棱角、连续高光与大面积阴影，贴图 128×128，17 色，无随机噪点。
上方内衬保持连续灰框与整块深灰色中心，下方为封顶面，用灰色回字纹表现深度。

开合结构
root → body；root → lid → lock。基础姿态完全关闭，箱盖与锁扣绕背面铰链打开 0°～90°。
Animate 面板内有 closed、open、opened、close 四个动作，开 / 合各 0.5 秒，20 Hz 采样。
主工程 UV 工作分辨率为 128×128，内嵌贴图；Java 静态工程使用 64×64 UV 工作分辨率，对应相同 128×128 PNG。
保存协议为 4.10，Blockbench 4.12 可读取，新版 Blockbench 5 会自动迁移动画轴向。不要只手工更改 format_version。
主工程以方块中心为 X/Z 原点，转轴 [0,6.32,5.12]；Java 静态导出的转轴对应 [8,6.32,13.12]。

交付文件
csgo_orange_case.png：128×128 PNG 贴图。
java_models/：关闭、打开状态的 Java 1.20.1 JSON 与 Java Block/Item 工程，以及 body / lid / lock 分体 JSON。
geckolib/：可供 Java 模组 GeckoLib 4 使用的 Geo 1.12.0 骨骼模型、1.8.0 动画 JSON 和 PNG。
assets/csgobox/：上述资产整理好的模组资源目录副本，普通物品入口默认为关闭状态。
model_manifest.json：模型 ID、分组名、转轴和动画名称；texture_layout.json：图集分区及配色。
仅交付模型、贴图、动画和说明，没有新增模组代码、容器行为或资源包替换逻辑；当前为单箱模型。
