芥末黄旧金属武器箱 · 无印花 · Minecraft Java 1.20.1 · 模型文件

主工程：csgo_yellow_metal_case_animated.bbmodel
沿用已确认的 MC 像素风格和 128×128 贴图，按用户提供的黄色金属箱参考制作。
正面三角标、CSGO 文字、侧面标记与虚线全部去除。
保留高身金属壳、竖向加强条、四道顶部压筋、两个黄色前扣、深灰凹入侧提手和挂锁。
主色为芥末黄，使用连贯的大色块、明确的折边高光和沟槽阴影表现金属；底部只保留连片的暗橄榄色磨损，没有随机斑点或细密噪声。
箱体和竖向折边使用一致的高度范围与相接色阶，避免转角处错位的亮暗条。
箱体主壳约 16×11.5×10.05 模型单位（宽×深×高），扣件和提手少量外凸；显示采用均匀缩放。
内部沿用灰色衬板，上盖中心为整片深灰，下箱平面封顶，使用回字形颜色过渡，不做内壁。

开合
root → body；root → lid → lock。body 固定，lid 为顶盖，lock 为挂锁；前扣随 lid 移动，侧提手固定在 body。
闭合为基础姿态，箱盖绕后侧铰链向后掀开 0°～90°。
Animate 面板有 closed、open、opened、close 四个动作，开 / 合各 0.5 秒，20 Hz 关键帧。
主工程为 Generic Model，内嵌 128×128 PNG，无需插件即可编辑并预览动画。
主工程转轴 [0,8.31,6.12]，对应 Java 方块坐标 [8,8.31,14.12]。
保存协议 4.10，Blockbench 4.12 可读取，Blockbench 5 会自动迁移动画方向；不要只手工修改 format_version。

文件
csgo_yellow_metal_case.png：128×128 PNG 像素图集。
java_models/：Java 1.20.1 关闭 / 打开静态 JSON，Java Block/Item 工程和 body / lid / lock 分体 JSON。
geckolib/：供 Java 模组 GeckoLib 4 使用的 Geo 1.12.0 骨骼模型、1.8.0 动画和 PNG。
assets/csgobox/：按模组资源路径整理的模型资产副本；普通物品入口默认关闭状态。
动画名称为 animation.csgo_yellow_metal_case.closed / open / opened / close。
model_manifest.json：骨骼、转轴和动画清单；texture_layout.json：图集分区与调色板。
仅交付模型、贴图、动画、预览和说明；没有模组代码或容器逻辑。原版 Java 方块 / 物品 JSON 本身不承载连续开合动画，接入时使用分体模型或骨骼模型。

检查
preview_states.png、preview_closed.png、preview_half_open.png、preview_open.png、preview_back.png 均为实际交付模型和贴图渲染。
validation.json：尺寸、分组、纹理、UV 和 0°～90° 每个整数角度的开合穿插检查，正常铰链接合除外。
codec_validation.json：与官方 Blockbench 4.12 编解码逻辑比对，并验证动作方向与新版迁移逻辑。
已检查文件及模型资产引用；未在 Minecraft 客户端实测。
