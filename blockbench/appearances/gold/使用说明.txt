CSGO 武器箱 · 开合兼容模型文件 · Minecraft Java 1.20.1

优先打开 csgo_box_animated.bbmodel
这是无需插件即可编辑、预览动画的 Blockbench Generic Model 工程。
默认姿态为关闭，箱体 body 固定，箱盖 lid 绕后侧铰链转动，锁扣 lock 是 lid 的子组。
root → body；root → lid → lock。全部组的基础旋转为 0，不再将打开角度烘焙到主工程中。
打开角度为 0°～90°。Animate 面板内有 closed、open、opened、close 四个动画。
open / close 各 0.5 秒，20 Hz 关键帧按原版开合进度的立方曲线采样。
模型工程使用 4.10 保存协议，兼容 Blockbench 4.12；新版 Blockbench 5 会自动迁移动画轴向。
不应手工仅将 format_version 改为 5.0，否则旧版关键帧的 X 方向会错误。

模型调整
恢复闭合箱盖的坐标和面 UV 朝向，取消原静态打开版的 90° 几何烘焙与 22.5° 元素旋转。
统一铰链转轴。锁扣恢复完整锁梁，调整至外侧以避开固定口沿，增加一条同材质连接件并随箱盖转动。
箱体和箱盖的尺寸比例保持，仍为下方平面封顶；内部纯色、下方回字形与外部金色贴图保留。
实际 PNG 仍为 128×128，逐字节与上一版一致。主工程 UV 工作分辨率同步为 128×128。
骨骼主工程以方块中心为 X/Z 原点，铰链坐标 [0,6.6,5.4]；静态 Java 导出使用方块坐标 [8,6.6,13.4]。

文件用途
csgo_box_animated.bbmodel：可活动主工程，内嵌贴图，建议继续编辑此文件。
csgo_box.png：通用贴图，与已确认的上一版完全相同。
java_models/csgo_box_closed.json 和 csgo_box_open.json：合法的 Java 1.20.1 关闭 / 打开静态模型。
java_models/*.bbmodel：对应的 Java Block/Item 工程，便于直接编辑静态模型。
java_models/parts/*.json：body、lid、lock 三个部件，均为闭合基础坐标，供后续按铰链驱动。
这几份 Java JSON 为静态资产，动画信息在主工程与 animations 文件内，不应期待普通 JSON 自动播放。
geckolib/geo/csgo_box.geo.json：Geo 1.12.0 骨骼模型，供 Java 模组的 GeckoLib 4 使用。
geckolib/animations/csgo_box.animation.json：对应四个动作；贴图在 geckolib/textures/。
不依赖 uv_rotation 扩展，原有 180° 面旋转已经等效折叠为 UV 端点。
assets/csgobox/：上述 Java 模型、贴图、Geo 和动画按模组资源路径整理好的副本；普通物品入口默认关闭。
model_manifest.json：骨骼名、转轴、坐标约定和动画名称。
本包仅包含模型、贴图、动画、预览与说明；没有新增模组代码、容器逻辑或资源包替换逻辑。
当前为单箱模型，未制作双箱的左右半模型。

验证
检查全部分组引用、贴图内嵌一致性、闭合与打开状态、Java 元素边界和 UV。
核对还原前后的箱盖几何和 UV 对应；Geo 导出再导入后坐标与 UV 一致。
检查 0°～90° 每个整数角度，箱盖 / 锁扣与固定箱体不穿插；铰链轴与连接片的正常接合除外。
preview_states.png、preview_closed.png、preview_half_open.png、preview_open.png 均为实际交付几何与 PNG 渲染。
validation.json 和 codec_validation.json 保存验证记录。未在 Minecraft 客户端内实测。
